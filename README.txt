CARA PUBLIKASI DENGAN GITHUB PAGES
1. Ekstrak ZIP ini.
2. Di GitHub, buat repository baru bernama photobooth-hari-guru-2026.
3. Pilih Public. Jangan centang README, .gitignore, atau license tambahan.
4. Tekan Create repository.
5. Pilih Add file > Upload files.
6. Upload index.html (dan README.txt jika mau), lalu tekan Commit changes.
7. Buka Settings > Pages.
8. Pada Build and deployment, pilih Deploy from a branch.
9. Branch: main; folder: /(root), lalu Save.
10. Tunggu beberapa menit. Link akan berbentuk:
    https://USERNAME.github.io/photobooth-hari-guru-2026/

Catatan:
- Kamera memerlukan HTTPS; GitHub Pages menyediakan HTTPS.
- Pengguna harus mengizinkan akses kamera di browser.
- Foto diproses di browser pengguna dan tidak diunggah ke server.
